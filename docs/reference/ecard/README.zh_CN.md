# AI Passport 电子校园卡 (eCard)

面向中小学 (K12) 与高校校园场景打造的纯净、安全、低功耗电子学生证 / 身份工牌应用。

---

## 一、 核心功能与设计原则

1. **NFC 电子工牌与身份展示 (P0)**：
   - **大尺寸标准证件照**：屏幕右侧开辟 125 × 175 像素标准 5:7 黄金比例相片区；
   - **纵向旋转条形码**：屏幕左侧垂直排列 Code128 标准条形码，适配侧向刷码；
   - **身份徽章与水印体系**：采用方案 A 高光胶囊徽章（学生活力蓝、教师曜石金），预留方案 B 自定义色值接口；
   - **互斥空间最大化**：平时显示【姓名班级大字 + 身份胶囊】；收到未读留言时变身【高亮橙黄提醒卡片】，播放完自动复原。
2. **双向语音留言与紧急求助 SOS (P0)**：
   - **长按 OK 键**：进入录音留言（最长 30 秒倒计时，无需长按不放），松手或短按 OK 提前完成，流式写入 Flash 并触发按需上传；
   - **短按 OK 键**：有未读消息时一键收听；播放中短按停止；
   - **短按 UP 键**：手动触发一次静默联网同步未读留言；
   - **长按 DOWN 键 (3秒)**：触发静默 SOS 紧急报警，静默录制 15 秒现场环境音并高优先级并发上报；
   - **课间时段自动同步**：内置学校作息表（09:40-10:00、11:40-12:10 等），仅在课间自动唤醒 WiFi 同步下行留言；上课期间 WiFi 硬件断电，杜绝干扰课堂纪律；
   - **低功耗息屏**：2 分钟无操作自动平滑降暗/浅休眠，任意按键瞬间唤醒。

## 二、 交互说明

| 触发手势 | 当前界面状态 | 执行动作 |
| :--- | :--- | :--- |
| **长按 OK 键 (≥1s)** | 空闲状态 | 启动 30 秒录音模态倒计时，无需长按不放 |
| **短按 OK 键** | 录音进行中 | 提前结束录音并极速上传 |
| **短按 OK 键** | 语音播放中 | 提前停止语音收听 |
| **短按 OK 键** | 空闲且有未读消息 | 启动 ES8311 播放语音留言，进度条流转 |
| **短按 UP 键** | 空闲状态 | 手动立即检查一次未读消息 |
| **长按 DOWN 键 (≥3s)** | 任意状态 | 触发紧急求助 SOS 静默报警与环境音回传 |
| **任意按键** | 屏幕暗屏中 | 立即唤醒并恢复 100% 背光，重置 2 分钟计时 |

## 三、 架构模块组织

* [`ecard_app.h`](../../../main/ecard_app.h) / [`ecard_app.c`](../../../main/ecard_app.c)：全局业务调度、按键分发与课间作息轮询
* [`ecard_ui.h`](../../../main/ecard_ui.h) / [`ecard_ui.c`](../../../main/ecard_ui.c)：240×320 竖屏 LVGL 界面、互斥展示容器与模态框
* [`ecard_barcode.h`](../../../main/ecard_barcode.h) / [`ecard_barcode.c`](../../../main/ecard_barcode.c)：Code128B 纵向旋转 90 度矢量条码生成器
* [`ecard_profile.h`](../../../main/ecard_profile.h) / [`ecard_profile.c`](../../../main/ecard_profile.c)：身份数据模型、方案 A/B 徽章色彩方案
* [`ecard_voice.h`](../../../main/ecard_voice.h) / [`ecard_voice.c`](../../../main/ecard_voice.c)：IMA-ADPCM 边采边压边存与 30 秒录音管理
* [`ecard_network.h`](../../../main/ecard_network.h) / [`ecard_network.c`](../../../main/ecard_network.c)：预置 WiFi 极速关联与课间作息区间判定
