# AI Passport 电子校园卡 (eCard)

面向中小学 (K12) 与高校校园场景打造的纯净、安全、低功耗电子学生证 / 身份工牌应用。

---

## 一、 核心功能与设计原则

1. **NFC 电子工牌与身份展示 (P0)**：
   - **工牌证件照**：首页 134 × 188 白色相框内嵌 130 × 184 RGB565 真人半身照；首页本身就是完整电子学生证，不再单独设“我的证件”页；
   - **条形码**：偶数位纯数字学号自动使用 Code128C（其余回退 Code128B），由 LVGL 绘制回调直接绘制在首页左侧，不占用 RGB565 图像缓冲；
   - **身份徽章与水印体系**：采用方案 A 高光胶囊徽章（学生活力蓝、教师曜石金），预留方案 B 自定义色值接口；
   - **互斥空间最大化**：平时显示【姓名班级大字 + 身份胶囊】；收到未读留言时变身【高亮橙黄提醒卡片】，播放完自动复原。
2. **七页交互界面**：
   - **首页**：居中校名与品牌金线、左侧竖向条码卡、大尺寸证件照、悬浮的姓名班级与身份胶囊、状态栏，以及与未读留言互斥的提醒卡；
   - **快捷菜单**：语音留言 / 随堂答题 / 古诗接句 / 英语单词 / 番茄钟 / 设备信息，UP/DOWN 选择；页面标题与一行说明合并显示，把纵向空间让给内容；古诗与单词先进入年级选择页（一至六年级）；
   - **语音留言**：过去 24 小时的滚动列表，按时间倒序（最新在上），同时包含收到与发出的留言；未读带蓝点，已读可重复点播；UP/DOWN 选择，OK 播放，长按 UP 同步，长按 OK 返回菜单；
   - **随堂答题**：10 道离线综合练习题，A/B/C 三选一，即时对错反馈与最终得分；长题干/长选项会自动降一档字号并撑高选项行，三行题面与两行选项都能完整显示；教师端下发与班级统计留到后续后端阶段；
   - **古诗接句**：1–6 年级共 60 首接句卡（每级 10 首），本版本为纯文字卡、不发音；正面显示上句，OK 翻面显示下句与大白话释义；
   - **英语单词**：1–6 年级共 293 个单词；正面显示单词本体；发音由小智服务器提供，OK 翻面显示中文词义、英文例句与翻译；背面不再重读单词；
   - **番茄钟**：专注时长可在未开始/已结束时用 UP/DOWN 在 5–50 分钟内按 5 分钟步进选择（默认 25 分钟），配 5 分钟短休息，每完成 4 轮自动转入 15 分钟长休息；OK 开始/暂停/继续，DOWN 结束本轮，进度环显示已用时间；进页即连好小智，专注期间长按 UP 可随时追问；
   - **设备信息**：电量、网络、固件、存储、模式与 SOS 提醒；断网时提醒条改为“网络未连接 / 长按 UP 重试连接网络”，长按 UP 立即重连；
3. **首次配置与设备重置 (P0)**：
   - **手机配网**：首次开机自动开启 SoftAP（`AI-Passport-XXXX` / `passport1234`）与强制门户，手机连上热点后自动弹出配网页。流程分两步：先填 Wi-Fi（设备自动扫描附近网络，手机从列表选择，也可手动输入）；连上后再自动跳转身份页（学生：8 位教育 ID、学校、班级、姓名、绑定家长手机号；教师：工号、学校、姓名、绑定手机号）。两步都完成才算配置完成；
   - **默认网络**：优先使用 NVS 中已配网凭据（`main/ecard_setup.h` 留空回退默认值）；断线后先按 5/10/20/30 秒快速重试，仍失败再退到每 2 分钟一次；连续失败 3 次或未配网时保持配网门户开启；
   - **设备重置**：设备信息页按 DOWN 进入确认页，OK 清除 Wi-Fi 与身份并重启；学习进度与闪卡状态不受影响；
   - **时间校准**：联网后启动 SNTP（`ntp.aliyun.com`、`cn.pool.ntp.org`），固定使用中国北京时间（UTC+8）。
4. **双向语音留言与紧急求助 SOS (P0)**：
   - **长按 OK 键**：启动真实麦克风录音。开机预留 40 KB，固定可录 10 秒（8 kHz IMA-ADPCM，4 KB/s，回放插值到 16 kHz）；堆充足时逻辑上限 15 秒。松手或短按结束后经网络桩上传，并立即本地回放；该路径不触发小智；
   - **短按 OK 键**：播放未读留言、停止播放、从首页进入菜单，或进入菜单选中项；
   - **短按 UP 键**：手动触发一次静默联网同步未读留言；按留言 ID 去重，已读的留言不会再次变回未读；
   - **长按 DOWN 键 (3 秒)**：进入 3 秒 SOS 确认页，保持按住发送，提前松手取消；
   - **课间时段自动同步**：内置学校作息表（09:40-10:00、11:40-12:10 等），仅在课间自动唤醒 WiFi 同步下行留言；上课期间 WiFi 硬件断电，杜绝干扰课堂纪律；
   - **低功耗息屏**：2 分钟无操作自动平滑降暗，任意按键瞬间唤醒。

中文界面使用五套自生成的 Noto Sans CJK SC 子集字库（9/12/16/22/48 px），每个文本控件都显式指定字体。源文件、许可、覆盖范围与重新生成命令见 [`assets/README.zh_CN.md`](../../../assets/README.zh_CN.md#ecard-界面字库)。

## 二、 交互说明

| 触发手势 | 页面 / 状态 | 执行动作 |
| :--- | :--- | :--- |
| 短按 OK 键 | 首页，无未读 | 打开快捷菜单 |
| 短按 OK 键 | 首页，有未读 | 播放未读语音留言 |
| 短按 OK 键 | 快捷菜单 | 进入当前选中项 |
| 短按 OK 键 | 证件 / 设备页 | 返回快捷菜单 |
| 短按 OK 键 | 留言页 | 播放选中的留言（已读也可重复收听） |
| 短按 OK 键 | 答题页，未作答 | 提交当前 A/B/C 选项 |
| 短按 OK 键 | 答题页，已作答 | 进入下一题 |
| 短按 OK 键 | 古诗/单词页，正面 | 翻面显示释义并朗读背面 |
| 短按 OK 键 | 古诗/单词页，本轮结束 | 返回快捷菜单 |
| 短按 UP 键 | 番茄钟，未开始/已结束 | 专注时长 +5 分钟（最长 50） |
| 短按 DOWN 键 | 番茄钟，未开始/已结束 | 专注时长 -5 分钟（最短 5） |
| 短按 OK 键 | 番茄钟，未开始/已结束 | 开始专注 |
| 短按 OK 键 | 番茄钟，进行中/已暂停 | 暂停或继续 |
| 短按 DOWN 键 | 番茄钟，进行中/已暂停 | 结束当前一轮 |
| 短按 DOWN 键 | 古诗/单词页，已翻面 | 记认识、抽下一张并朗读 |
| 短按 UP 键 | 古诗/单词页，已翻面 | 记不认识并回炉到本轮队尾 |
| 短按 OK 键 | 答题页，已完成 | 返回快捷菜单 |
| 短按 OK 键 | 录音中 | 提前结束录音并上传 |
| 短按 OK 键 | 播放中 | 停止播放并标记已读 |
| 短按 OK 键 | SOS 已发送 | 确认并返回首页 |
| 长按 OK 键 | 首页 | 启动 15 秒录音浮层 |
| 长按 OK 键 | 快捷菜单 | 返回首页 |
| 长按 OK 键 | 留言 / 答题 / 古诗 / 单词 / 番茄钟 / 设备页 | 返回快捷菜单 |
| 短按 UP 键 | 首页 | 手动立即检查一次未读留言 |
| 短按 UP 键 | 留言页 | 选中上一条（更新的） |
| 短按 DOWN 键 | 留言页 | 选中下一条（更旧的） |
| 长按 UP 键 | 留言页 | 手动立即检查一次未读留言 |
| 短按 UP 键 | 快捷菜单 / 答题页 | 选中项上移（循环） |
| 长按 UP 键 | 设备信息页（断网） | 立即重试 Wi-Fi 连接 |
| 短按 DOWN 键 | 快捷菜单 / 答题页 | 选中项下移（循环） |
| 长按 UP 键 | 答题 / 古诗 / 单词 | 让小智追问（按住说话，松手发送） |
| 长按 DOWN 键 | 任意页面 | 进入 3 秒 SOS 确认浮层 |
| 松开 DOWN 键 | SOS 确认中 | 取消报警 |
| 短按 OK 键 | SOS 已发送 | 确认并返回首页 |
| 任意按键 | 屏幕暗屏中 | 立即唤醒并恢复 100% 背光，重置 2 分钟计时 |

## 三、 架构模块组织

* [`ecard_app.h`](../../../main/ecard_app.h) / [`ecard_app.c`](../../../main/ecard_app.c)：全局调度、页面导航、SOS 确认状态机与课间同步循环
* [`ecard_ui.h`](../../../main/ecard_ui.h) / [`ecard_ui.c`](../../../main/ecard_ui.c)：240×320 LVGL 竖屏界面、十一个按需创建页面、四类浮层、条码绘制回调与空闲降亮计时
* [`ecard_quiz.h`](../../../main/ecard_quiz.h) / [`ecard_quiz.c`](../../../main/ecard_quiz.c)：10 道离线题库与作答/计分状态机
* [`ecard_setup.h`](../../../main/ecard_setup.h) / [`ecard_setup.c`](../../../main/ecard_setup.c) / [`ecard_setup_validate.c`](../../../main/ecard_setup_validate.c)：NVS 首配存储、身份校验与档案写入
* [`ecard_netlink.h`](../../../main/ecard_netlink.h) / [`ecard_netlink.c`](../../../main/ecard_netlink.c)：STA 联网、断线后 5/10/20/30 秒快速重试并退到 2 分钟稳定间隔、扫描期间的主动断开不计失败、配网回退
* [`ecard_portal.h`](../../../main/ecard_portal.h) / [`ecard_portal.c`](../../../main/ecard_portal.c)：SoftAP + HTTP 表单，保存后重启
* [`ecard_time.h`](../../../main/ecard_time.h) / [`ecard_time.c`](../../../main/ecard_time.c)：SNTP 授时与固定 UTC+8 时区
* [`ecard_pomodoro.h`](../../../main/ecard_pomodoro.h) / [`ecard_pomodoro.c`](../../../main/ecard_pomodoro.c)：专注计时状态机，支持暂停/继续、自动阶段切换与四轮后长休息
* [`ecard_cards.h`](../../../main/ecard_cards.h) / [`ecard_cards.c`](../../../main/ecard_cards.c)：生成的 1–6 年级古诗/单词卡表与单词发音扁平下标映射
* [`ecard_flashcard.h`](../../../main/ecard_flashcard.h) / [`ecard_flashcard.c`](../../../main/ecard_flashcard.c)：任意年级卡组上的待学队列与不认识回炉状态机
* [`ecard_barcode.h`](../../../main/ecard_barcode.h) / [`ecard_barcode.c`](../../../main/ecard_barcode.c)：Code128C/Code128B 自动编码器、横向绘制回调与旧版 RGB565 纵向渲染器
* [`ecard_photo.h`](../../../main/ecard_photo.h) / [`assets/images/ecard_portrait.c`](../../../assets/images/ecard_portrait.c)：生成的首页工牌与证件页 RGB565 证件照描述符
* [`ecard_profile.h`](../../../main/ecard_profile.h) / [`ecard_profile.c`](../../../main/ecard_profile.c)：身份档案、有效期与方案 A/B 主题
* [`ecard_voice.h`](../../../main/ecard_voice.h) / [`ecard_voice.c`](../../../main/ecard_voice.c)：IMA-ADPCM 流式编解码、堆上 15 秒录音缓冲、峰值电平检测与本地回放解码；网络下行留言暂无音频负载，回放时使用 [`assets/sounds/ecard_demo_voice.c`](../../../assets/sounds/ecard_demo_voice.c) 内置演示语音
* [`ecard_network.h`](../../../main/ecard_network.h) / [`ecard_network.c`](../../../main/ecard_network.c)：预置校园 WiFi 管理与课间时段判定
* [`assets/fonts/`](../../../assets/fonts/)：生成的 LVGL 中文字库与 Noto Sans CJK SC 许可
* [`tools/generate_ecard_fonts.py`](../../../tools/generate_ecard_fonts.py)：可复现的字库子集生成器
* [`tools/generate_ecard_photo.py`](../../../tools/generate_ecard_photo.py)：证件照裁切、增强与 RGB565 描述符生成器
* [`tests/test_ecard_fonts.py`](../../../tests/test_ecard_fonts.py)：逐字库覆盖检查、负样例与构建集成门禁
